- MCPL references (RFC-005): display labels now drop the Arabic letter mark (U+061C) along with the other bidi controls, and so do the server's claimed type where `fetch_reference` falls back to it and `save_recent_image`'s refusal of a reference. A label left empty once sanitized is left out of the stub.
- An `expiresAt` rejected as a field (past its 64-character maximum, or not a string, null included) fails closed like an unparseable one: the reference is treated as already expired, never as immortal. The fetcher won't fetch it and the eager default doesn't pick it, while a copy saved earlier is still served. Its refusal says which it was: an expiry that has passed, one that doesn't parse, or one rejected as a field. An expired reference no longer takes one of a result's eager-fetch slots.
