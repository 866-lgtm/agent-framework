- A runtime connect, a restart or a disconnect of an MCPL server whose connect is still in flight is now refused before it changes anything, with `MCPL server "<id>" has a connect in flight; try again once it settles`. Nothing stops a connect in flight. A second connect went ahead beside it, and its connection replaced the first in the registry without closing it. A disconnect removed the server's config and tool prefix, and the connect then registered the server without them, where no call reached it and only another disconnect cleared it. A restart begins with that disconnect.
