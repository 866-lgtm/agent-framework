- The `SIGUSR2` diagnostics dump prints a line for each framework from its `create()` until its `stop()`, and one line, `[diagnostics] no framework is running in this process`, when there is none. Before, every `create()` added a `SIGUSR2` listener that nothing removed, so a process that made one framework after another, as connectome-host does on each session switch, kept every stopped framework reachable and printed a stale dump of each on every signal. Now one listener serves the process: the first `create()` installs it, and it stays for the process's life, since a process whose last `SIGUSR2` listener is removed is ended by the next `SIGUSR2`. A framework's own line is unchanged.
