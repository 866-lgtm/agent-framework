- `resume()` no longer throws when one agent's runtime settings can't be read, as when its context manager (0.14, required since 0.21.1) refuses while its strategy's initialization is pending or has failed. It warns, naming the agent and the error, and proceeds without a feasibility verdict for that agent, as it does for an agent whose strategy can't preview.
- Offline recovery (`createOfflineRecoveryBranch`) reads a sharded message's body as context-manager 0.14.0 does: a message continues the body before it only when it carries the same group id at a higher shard index. A document posted twice stores two copies under one group id, so an anchor at the end of one copy, or a suppression of one copy alone, is no longer refused. A selection inside one copy is still refused. An anchor at the end of a write that was cut short keeps that partial body and leaves out its retry, which context-manager 0.14.0 reads as a body of its own. Each suppressed interval is now removed as a range, so suppressing a one-shard copy no longer fails at removal.
