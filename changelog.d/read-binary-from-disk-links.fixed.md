- `WorkspaceModule.readBinaryFromDisk` could read outside its mount through a symlink: it followed one at the path or among the directories on its way, wherever it led, whatever the mount's `followSymlinks` said. It now reaches a file as `readFileFromDisk` does, so it refuses a symlink the mount doesn't follow, and on any mount a file that resolves outside it, in `readFileFromDisk`'s words. Its own answers for a missing file, a file that isn't regular and a file over `maxBytes` are kept, and a path through a file, which gave the system's message with the absolute path, now answers "File not found on disk".
