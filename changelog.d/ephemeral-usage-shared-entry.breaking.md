- **Hosts that read usage by agent:** every ephemeral agent's usage (`createEphemeralAgent`) now counts in one shared `byAgent` entry, named `ephemeral agents` and marked `ephemeral: true`, instead of an entry under each agent's own name. Each ephemeral agent runs under a new name, and the usage record is rewritten whole after every inference, so an entry per name made every later write bigger for good.
  - **Migration:** a host that looks up a subagent's usage by its name in `getSessionUsage()` no longer finds it there, and reads the entry marked `ephemeral: true` instead, which holds every ephemeral agent's usage together. A host that lists `byAgent`, such as connectome-host's `/usage` and its web UI's per-agent cost, shows one line for all subagents instead of one each.
  - **Stored entries:** at the first start after upgrading, the entries a store holds under ephemeral agents' names fold into the shared entry. An entry folds when the store has that name's ephemeral namespace (`subagent/<name>`), unless a persistent agent has the name: a configured agent, the configured subconscious, or one with a resident's or a conversation agent's namespace (`agents/<name>`, `conversations/<name>`).
  - **Unchanged:** the totals, the inference count and each other agent's entry. The `usage:updated` trace still names each run's own agent.
  - **Rolling back:** a framework from before this shows the shared entry as an agent named `ephemeral agents` and writes it back without its mark, and this version takes it back as the shared entry. If an agent is itself named `ephemeral agents`, the older framework keys both by that name, so the shared entry replaces the agent's own, and after upgrading again that entry stays the agent's. The totals don't change.
