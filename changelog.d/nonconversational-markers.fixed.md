- **Edit/delete/reaction-remove markers now preserve explicit-send suppression, like reaction markers** (#157). `isConversationalInjection` exempted only `chat:reaction`, so the RFC-001 marker tags `chat:edited`, `chat:deleted` and `chat:reaction-remove` (now delivered as synthetic incoming messages by e.g. zulip_mcp) cleared explicit-send suppression — an edit notice arriving right after a `send_message` re-opened auto-routing for the same round's prose. The four tags live in a shared `NON_CONVERSATIONAL_TAGS` set (`src/mcpl/tags.ts`). All four marker tags also leave ChannelRegistry's default publish channel and `context.incoming`'s message/thread anchor unchanged. An edit the agent sees first, because it replaced a message the agent hadn't been shown yet, still counts as that message and clears explicit-send suppression like one. The host knows that case when RFC-006 coalescing replaces a message whose producer marked its first occurrence `initial` and of which no version has reached the agent yet. `channel_publish`'s description now says that an omitted `channelId` goes to a conversation agent's own channel when it is bound to one.
