- A state that can't be registered, for any reason but that it already exists, now fails the call that registers it (#385). Those calls are `AgentFramework.create()`, `addModule()`, the workspace's `initStore()`, and the MCPL checkpoint, host-state and tune-out coordinator states. Their registrations swallowed every failure, a closed store or an I/O error alike, so the failure surfaced at a later read or write of that state, under that call's name. A state that already exists, as it does when a store is reopened, is still registered without complaint.
