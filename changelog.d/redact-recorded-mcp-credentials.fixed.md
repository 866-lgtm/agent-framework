- Server and transport diagnostics recorded by the framework redact known URL credentials and the configured static token, including encoded and decoded forms. An HTTP error that echoes a credential-bearing request path no longer copies the credential into connection traces, console errors, ops alerts or modern tool-call failures. Stderr traces use the same filtering. Short standalone strings remain unchanged; short query values are removed as whole `name=value` strings. Access-provider cached tokens and unknown secrets are outside this filtering, and JSON-RPC tool answers and direct host connection errors retain their pass-through contract.
