- `quiesce()` now writes the host-mode record before it marks the host quiesced. When that write failed, `quiesce()` rejected with the host quiesced in memory while its record said it was serving, so a restart booted serving, and a second `quiesce()` resolved without writing the record. Now a failed write leaves the host serving, as its record says, and the next `quiesce()` quiesces and writes it.
