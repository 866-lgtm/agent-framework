- **Hosts:** explicit `allowedTools` lists must name each permitted utility as well as `utils`, or use `"all"`. Hosts that construct depth-limited lists can obtain the existing namespaced utility catalogue through `getAllUtilities()`. Callers using `"all"` retain their behavior. Adopt this change with the connectome-host release containing https://github.com/anima-research/connectome-host/pull/191; its minimum released version is pending that release. Release this compatibility change in a minor version so hosts using `^0.22.1` do not receive it as a patch without the companion.
